⌥⌘o	Go to Symbol (columns)
⇧⌘O	Go to File (open and recent tabs)
⇧⌘A	Find Action

⌘e	Recent Files
⌃⇥ / ⌃⇧⇥	Switcher (hold ⌃, release to open)
⇧⌘/	Keymap Reference (this window)
